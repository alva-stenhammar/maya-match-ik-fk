# Match IK/FK

### This script matches FK to IK and vice versa! How neat (⁠╹⁠▽⁠╹⁠)

_**OBS!** Only works limbs with three joints (basically biped rigs)._


This is a Maya script written mostly for personal use, so the naming conventions are specific to what I like to use in my rigs.

The naming convention for bind joints is **L_shoulder_BIND_JNT**, and for IK/FK **L_shoulder_IK/FK_JNT**. I'm making use of Maya's new offset parent matrix so only one control group is needed! The controls need to be parented under a group and have these naming conventions: **L_shoulder_IK/FK_CTRL** & **L_shoulder_IK/FK_GRP**.
